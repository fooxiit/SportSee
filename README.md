SportSee – Tableau de bord d’analyses sportives

1. Contexte du projet

Ce projet a été réalisé dans le cadre de la formation Développeur d'application JavaScript React proposée par OpenClassrooms.

L’objectif est de développer une application web permettant de visualiser des données sportives à travers un dashboard interactif, en utilisant React.

2. Objectifs pédagogiques

Développer une application front-end avec React

Implémenter des graphiques interactifs à partir de données externes

Séparer la logique métier, les composants et les services

Générer une documentation technique

4. API – Backend OpenClassrooms
   4.1 Présentation

Le projet utilise une API REST fournie par OpenClassrooms afin de récupérer les données sportives des utilisateurs.

Dépôt de l’API :
https://github.com/OpenClassrooms-Student-Center/SportSee.git

4.2 Remarque importante

Le backend doit être lancé avant le front-end pour que l’application fonctionne correctement.
